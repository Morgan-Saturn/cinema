Il s'agit d'une petite page web construite sans aucun framework, librairie externe, ni dépendance. L'objectif est d'extraire un flux rss et en implanter les informations voulues en nombre de résultats voulus dans une grille de 3 colonnes tout en assurant le responsive. L'objectif final est de m'entraîner en php. =D


# Routes

pages/cinema/liste renvoie la liste de toutes les news (index.html).
pages/cinema/details renvoie les détails de l'article sélectionné (details.html).
api/cinema/liste renvoie le json et la pagination.
api/cinema/:id renvoie le détail de l'article en json.
